## 🌟 About This Repository

This repository contains my practice programs and mini projects written in **8086 Assembly Language** using **Emu8086**.

The programs cover:

- 🖨️ Character & String Printing
- ➕ Arithmetic Operations
- 🔀 Comparison & Conditional Statements
- 🔁 Loops
- 🔢 Number Operations
- 🧮 Division, Quotient & Remainder
- ⚖️ Even & Odd Numbers
- 🔤 Vowel Counting
- 🧩 Mini Projects

This repository represents my learning journey with **8086 Assembly Language**.

### 🧮 02 — Vowel counter
**File:** `project_2_vowel_counter.asm`

A simple 8086 Assembly program that takes a word from the user and counts the total number of vowels.

### ✨ Features

- Takes input from the user
- Supports uppercase and lowercase vowels
- Counts `A, E, I, O, U`
- Displays the total number of vowels

### 💻 Example

```text
Enter a word!: Hello

Total vowels: 2
